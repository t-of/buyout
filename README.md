# BUYOUT — 架空の会社を買い占める放置相場

架空の会社の株を売り買いして、配当で資産を増やす放置ゲーム。閉じている間も相場とニュースは動き続け、開くと留守の間の配当がまとめて入る。全 8 社の株を買い占めたらクリア。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/buyout/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

1. 手持ちは 10,000 円（ゲームのお金）。会社を選んで株を買う。
2. 持っている株には **90 秒ごと**に配当が入る。閉じていても、開いたときに留守の間の分（最大 8 時間）がまとめて入る。
3. 株価はいつも上がり下がりし、ニュースで急に動く。安いときに買い、高いときに売れば増える。
4. 増えたお金でもっと大きな会社を買っていき、**全 8 社の株を全部持ったらクリア**。

- 会社の行をタップすると、チャートと売り買いのシートが出る。買うは「現金の 1/4」「1/2」「買えるだけ」、売るは「半分」「全部」。
- 現実の 1 秒 = ゲーム内の 1 日。90 秒で 1 期、360 秒で 1 年。

これはゲームです。登場する会社・株価・ニュースはすべて架空で、実在の会社・市場・出来事とは関係ありません。ゲームのお金は本物のお金ではなく、買うことも換金することもできません。記録はこの端末にだけ保存します。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

一度開けば、オフラインでも遊べます。

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
node test.mjs                 # 株価・ニュース・配当・進める・売り買い・保存・数の書き方のテスト（フレームワークなし）
```

| ファイル | 中身 |
|---|---|
| `game.js` | 会社の表（数値の調整はここ）・株価・ニュース・配当・`advance`・売り買い・保存の形・数の書き方（DOM に触らない） |
| `main.js` | 画面・シート・効果音・保存・1 秒の時計 |

### しくみ

- 株価とニュースは時刻の関数。同じ時刻からは必ず同じ値が出る（整数のハッシュで作ったバリューノイズを 3 つ重ね、ニュースの効きを掛ける）。種は固定なので、どの端末でも同じ相場になる。
- 開いたとき・戻ったとき・開いている間の 1 秒ごと、すべて `advance(状態, 今)` を通す。経過が負（時計が戻された）なら 0、8 時間を超えた分は数えない。配当は期の境目をまたいだ回数 × 1 期分で、円未満の端数は持ち越す。
- 金額・株数は BigInt（最後の会社の発行済株式数と買い占めの額が Number の安全な範囲を超える）。保存は文字列。
- 保存のキー: `buyout.save`（遊びの状態）、`buyout.settings`（音）。読めないときは `buyout.save.broken` に写してから新しく始める。
